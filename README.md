# Dharma Shop — обновления

Публичная точка раздачи обновлений для [Dharma Shop](https://github.com/shivayanamahom/dharma-shop): ленты обновлений Joomla (`updates/*.xml`) и установочные архивы (в разделе [Releases](https://github.com/shivayanamahom/dharma-shop-updates/releases)).

Ленты читает Joomla сама (Система → Обновления); вручную ничего скачивать не нужно. Файлы генерирует `dev/release.py` из основного репозитория, править их вручную не следует.

Пакет и каждое расширение (плагин, модуль, компонент) имеют отдельную ленту и версию: если изменился один плагин, обновляется только он.
